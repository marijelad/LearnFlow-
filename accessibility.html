Accessibility

Designed to support more learners.

This demo uses semantic structure, keyboard-accessible controls, visible focus styles, alt text, responsive layouts, and readable contrast as a baseline.

What is included

  • Semantic headings and landmarks.
  • Text alternatives for meaningful local artwork.
  • Responsive layouts that reflow on small screens.
  • Controls with labels or accessible names.
  • Reduced reliance on color alone for meaning.

What a production audit would add

A real product launch should include automated and manual accessibility testing, keyboard-only review, screen-reader checks, zoom testing, motion preferences, and ongoing issue tracking.
