# LearnFlow — Online Course Platform Portfolio Project

LearnFlow is a multi-page, responsive front-end website designed as a realistic online learning platform demo.

## Included
- 55 HTML pages
- Responsive desktop/tablet/mobile layouts
- Course catalog with search, filters, and sorting
- 12 course detail pages
- Lesson pages and quiz flow
- Learner dashboard, progress UI, wishlist, certificates, profile
- Instructor dashboard, analytics, and course builder
- Pricing and demo checkout flow
- Blog/resources, help center, contact, careers, legal, accessibility, 404
- Dark mode, reveal animations, hover effects, localStorage demo interactions
- Local SVG artwork and course covers (no external image dependency)

## Run locally
Open `index.html` directly, or run a small static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages
Push this folder to a GitHub repository, then enable GitHub Pages from the repository settings using the main branch/root folder.

## Important
This is a portfolio demonstration. Authentication, checkout, ratings, users, instructors, counts, testimonials, and pricing are fictional. No real payment backend is connected. Do not enter sensitive or financial information.
